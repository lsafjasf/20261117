# 低重力月球运输车 · 温室补给任务

纯原生 HTML5 Canvas + WebAudio 实现，无第三方运行时依赖。驾驶运输车把
**水箱与种子**送到三个温室舱，再返回着陆器即获胜。

## 运行

```bash
npm start          # 启动静态服务器，打开 http://localhost:8080
# 或直接用浏览器打开 index.html
npm test           # 运行 12 项自动化测试（引擎复现性 + 浏览器集成冒烟）
```

## 玩法与按键

- `W / ↑` 油门，`S / ↓ / 空格` 制动，`A D / ← →` 转向
- `P / Esc` 暂停，`R` 重开，`C` 失败后从最近检查点继续
- `F5` 保存到 `localStorage`，`F9` 重新载入（已拦截浏览器默认刷新）
- 面板按钮提供相同操作，并可输入固定 seed 后重开

## 物理与任务机制

- **低重力弹跳**：撞击岩石、越过坑缘会让车体离地，离地时转向衰减
- **载荷影响制动**：整车质量 = 干质量 + 剩余水箱/种子质量，载荷越重，
  当前制动距离越长（HUD 实时显示）
- **陨坑边缘滑坡**：以超过 140 u/s 越过坑缘触发滑坡失败；在坑内滞留超过
  4 秒判定搁浅
- **岩石碰撞**：低速为弹性反弹，撞击法向速度超过 170 u/s 车体损毁
- **电量约束**：行驶/制动/怠速持续耗电，返回着陆器可充电；电量归零且不在
  着陆器旁即失败，无法返航
- **风扰**：风向与强度按确定性时间表周期变化，HUD 与画面箭头实时显示
- **交付与胜利**：进入未补给的温室舱自动卸下 1 份水箱 + 1 份种子；三舱全部
  完成并回到着陆器判定胜利

## 固定 seed 与复现

- 所有地图生成（陨坑、岩石、月尘、风向表）均走可序列化的 `mulberry32` PRNG，
  渲染层视觉随机数使用独立 PRNG，不进入存档，因此不影响模拟复现
- 同一 seed 下地图、任务布局、障碍 ID 与生成顺序完全一致；同输入下轨迹逐帧一致
- 存档为版本化 JSON 快照，载入后对象位置、资源、胜负判定不变，可继续模拟
- 重开会基于当前 seed 重建整局：目标交付状态、电量、载荷、检查点、日志全部
  恢复初始，而不是只重置车辆位置

## 检查点与失败恢复

- 着陆器为初始检查点，沿途 4 个检查点首次进入时保存完整快照
- 失败（碰撞/搁浅/滑坡/断电）后按 `C` 或点击「检查点继续」，回到最近经过的
  检查点，保留该检查点之前的交付与资源进度，失败标记清除

## 可重复调试场景

- 「演示：正常路线」使用内置自动驾驶沿规划航点（画面蓝色虚线）绕坑行驶，
  可稳定复现三舱交付 + 返航胜利
- 「演示：高速碰撞」让车直线加速冲向 `rock0`，复现碰撞失败，再用 `C` 演示恢复
- 「调试覆盖层」显示 seed、时间、坐标、轮速、整车质量、当前制动距离、
  当前检查点与弹跳次数

## 目录结构

- `src/prng.js` 确定性随机数
- `src/world.js` 固定 seed 世界生成与风向查询
- `src/engine.js` 纯逻辑模拟引擎（物理、失败判定、交付、检查点、存档）
- `src/render.js` Canvas 渲染（月尘、陨坑、舱室、车辙、路径、风向）
- `src/audio.js` 随轮速变化的 WebAudio 引擎声与事件音
- `src/main.js` 浏览器主控（循环、输入、HUD、暂停/重开/存档）
- `test/engine.test.js` 11 项引擎验收测试
- `test/browser.smoke.js` 浏览器脚本集成冒烟测试
