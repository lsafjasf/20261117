# 听诊故障诊断台

三台故障机器分别发出连续音、敲击音、摩擦音(故障分布每局随机)。
把听诊器贴到设备图上的不同听诊点,根据听到的声音判断每台机器的故障类型,
三组诊断全部正确即成功。

## 运行

```bash
npm run serve   # 打开 http://localhost:8080
```

或直接双击 `index.html`(file:// 亦可运行)。

## 玩法与规则

- 点击设备图上的圆形听诊点移动听诊器;每台机器 3 个点,机器间另有 2 个混合区点。
- 贴点离故障机越近声音越清晰;位于机器之间会听到多台机器的混合声。
- 设备负载滑块会改变背景嗡声的电平/频率、敲击节拍快慢与摩擦音中心频率。
- 听诊增益超过 0.7 后进入waveshaper 失真区(界面有“失真中”提示)。
- 每台机器在下拉框中选择故障类型,三组全部正确即成功并揭示答案。

## 声音与试听

- 全部声音由 Web Audio 实时合成:连续音(锯齿+谐波+颤音)、敲击音(扫频正弦
  突发,绝对时间调度无累积漂移)、摩擦音(种子噪声+带通+LFO)、负载嗡声。
- 试听状态三档:主输出(经压缩效果链)/ 旁路(跳过效果)/ 静音。
- 传输:播放、暂停(立即停止并断开全部声源节点,无尾音)、重播、单步(暂停态
  下精确触发一次敲击节拍)。
- 实时显示:波形、左右声道电平、声道数、活动节点数、播放状态。

## 参数保存 / 重载 / 导出验证

- “保存参数”写入 localStorage 并下载 `params.json`;“重载参数”恢复全部状态。
- “导出 WAV”用 OfflineAudioContext 确定性渲染 4 秒 44.1kHz 立体声 16bit WAV,
  并显示时长/声道/左右峰值及峰时刻/敲击间隔;重载参数后再次导出会自动与上次
  对比(时长、声道数、左右峰值、峰时刻需全部一致)。
- “维度自检”离线渲染验证至少三个维度随操作真实变化:
  左右声道(听诊点移动 → L/R 峰值比变化)、频段(负载 → 嗡声频带迁移)、
  节拍(负载 → 敲击间隔变化),外加同参数两次渲染完全一致的确定性检查。
