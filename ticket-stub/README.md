# 可撕票根生成器

在浏览器中打开 `index.html`（或 `python3 -m http.server` 后访问）即可使用。

## 功能

- **票根绘制**：Canvas 绘制票面、撕线（虚线 + 半圆缺口）、验证纹样（扭索纹）与文字
- **可编辑**：活动名称、场次、座位、日期、编号、字体、字号缩放、撕线位置、票宽/票高
- **排版规则校验**：所有修改先校验后应用；违反规则（文本越安全边距、编号/纹样跨撕线、
  垂直重叠或裁切）时保留原有内容与输入，并提示具体违反的规则与修复方法
- **撤销 / 重做**：按钮或 `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`
- **保存 / 重新载入**：自动存入 localStorage，也可导出 / 导入工程 JSON，文字与图形保持可编辑
- **导出**：SVG（矢量，与预览同一布局源）与 PNG（2 倍分辨率，同一 Canvas 绘制函数）
- **批量生成**：布局保持一致，仅编号递增，导出多张 SVG
- **测试用例**：标准案例、极端长文本、极小尺寸一键载入

## 结构

- `js/model.js` — 状态、布局推导、规则校验（Canvas/SVG/批量共用）
- `js/pattern.js` — 验证纹样路径生成器
- `js/render.js` — Canvas 渲染（预览与 PNG 导出共用）
- `js/svg.js` — SVG 导出
- `js/app.js` — 交互、历史、存取、导出、批量

## 测试

```
node test/run-tests.js
```

覆盖三组案例的安全边距 / 重叠 / 裁切不变量、非法输入拦截、SVG 与布局一致性、
批量生成布局稳定性。
