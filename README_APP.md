# 钻孔地层柱交互对比应用

基于钻孔数据的可交互地层柱单页应用：Canvas 绘制岩性纹理与深度刻度，双孔对比连线，
缺失层显式占位且绝不误连；地图、曲线、列表、统计与 SVG 导出共用同一数据版本。

## 运行

```bash
npm install          # 安装测试用 jsdom（应用本身零运行时依赖）
npm run serve        # http://localhost:8710/
npm test             # 18 个 Node 测试（含浏览器装配冒烟）
```

直接用浏览器打开 `app/index.html` 也可运行（ES Module，建议走本地服务器）。

## 三组数据集

- `normal` 正常数据：2 孔 × 7 层，层序完整，无质量问题。
- `missing` 缺失层数据：ZK04 在 17.6–22.4 m 未取芯（缺 N1 砾石层），生成缺失段占位且对比不连线。
- `abnormal` 异常数据：注入层位/采样完全重复、冲突重复、层序倒置、深度重叠、GR 超界（-15、310）。

## 数据管线（全部为纯函数，可独立测试）

1. `dedupe.js` 去重：完全重复静默丢弃；同深度冲突保留首条并记录问题。
2. `validate.js` 校验：倒置/重叠/未知岩性剔除；GR 超物理量程判异常剔除。
3. `column.js` 补缺：相邻层位不衔接处生成 `gap` 未取芯占位。
4. `resample.js` 重采样：0.5 m 固定网格，同网格取均值，无数据/缺失段网格补 `null`。
5. `correlation.js` 对比：仅同岩性代码连线，缺失层不产生任何连线。
6. `filters.js` / `stats.js`：时间窗口、钻孔、岩性筛选与五种统计口径实时聚合。
7. `pipeline.js` 输出带版本号（FNV-1a 哈希）的视图模型，所有视图只消费该模型。

## 同步与状态保留

- 地图点选、图例筛选、窗口/口径切换均经 `Store` 广播，地层柱、曲线、列表、统计同步刷新。
- 每个“数据集 × 时间窗口”独立保存快照（筛选、选中层位、深度显示范围），切回前一条件原样恢复。
- 顶栏始终显示：当前数据集、数据版本、时间窗口、统计口径、钻孔/岩性筛选、深度范围与样本出入计数。
- 导出日志记录每次导出的版本、窗口、口径、空结果标记、图元数与数值指纹。

## 导出一致性

- `exporter.js` 由当前视图模型生成独立 SVG，屏幕与 SVG 共用 `geometry.js` 几何与同一套格式化函数。
- 数值指纹对聚合结果与重采样序列哈希，写入 SVG 页脚；测试逐字校验 SVG 中统计值等于屏幕模型。
- 图形不写死任何预设结果：切换口径/筛选后 SVG 内容与版本号随之变化；空结果导出明确标注且无数值图元。

## 测试覆盖（`app/tests/`）

- `pipeline.test.js`：去重、异常剔除、缺失占位、防误连、重采样补缺、聚合正确性、版本稳定性。
- `store.test.js`：窗口/数据集快照保留、空结果（Q4）、正常筛选（Q1）、零钻孔降级。
- `export.test.js`：图数一致、动态导出、空结果导出、缺失层图案、导出日志。
- `browser-smoke.test.js`：jsdom 下完整装配，模拟图例/列表/地图点击与导出链路。
