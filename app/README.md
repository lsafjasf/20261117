# 雨声分离台（Web Audio 实时合成）

雨棚敲击、地面积水、远处雷声三组声音全部由 Web Audio 实时生成，玩家用
**频段（带通中心频率 + Q）** 与 **噪声门限** 把它们分到三条独立轨道。
界面用 Canvas 绘制频谱、能量条与可拖拽主推子，每轨显示实时电平与左右声道平衡。

## 运行

需要通过 HTTP 提供页面（`file://` 下浏览器会拦截 Blob 形式的 AudioWorklet 模块）：

```bash
cd app
python3 -m http.server 8731
# 浏览器打开 http://127.0.0.1:8731/index.html
```

## 声音与信号链

三类声音均为实时合成，无任何音频文件：

- 雨棚敲击：高通白噪声短脉冲，快速衰减，高频段。
- 地面积水：低通噪声团，较慢起音，中频段。
- 远处雷声：低通噪声轰鸣 + 次低频正弦染色，低频段，慢速包络。

每轨处理链（在线播放与离线导出共用同一条）：

```
实时合成源 -> BiquadFilter(bandpass) -> GateWorklet(门限)
          -> MeterWorklet(电平表) -> Gain(音量) -> StereoPanner(声像) -> 总线
                          旁路支线：bandpass 输出直达总线（绕开门限）
```

- `worklets.js`：NoiseGen / EnvelopeGen / GateWorklet / MeterWorklet 处理器源码，
  运行时以 Blob URL 注册，在线 `AudioContext` 与离线 `OfflineAudioContext` 共用，
  保证“听到的”和“导出的”是同一条算法链。
- 确定性 PRNG（mulberry32）：在线与离线使用相同随机序列，结果可重复。

## 功能清单

- 走带：播放、暂停（挂起上下文，声音立即停止）、停止（关闭并销毁全部节点）、
  重播、单步（离线渲染当前一步并预览，步进位置前进）。
- 三种试听状态：主输出、旁路（绕开门限/主链）、静音（监听增益为 0）。
- 每轨：单轨试听（solo）、静音、频段/Q/门限/音量/声像调节、恢复原混音。
- 实时显示：每轨能量条与门限刻度、左右声道平衡、主输出 L/R 电平表、
  主输出 FFT 频谱、活动节点计数、上下文状态、节拍漂移。
- 参数保存：写入 localStorage 并下载 JSON；可从文件载入并即时应用。
- WAV 导出：离线渲染 16-bit 立体声 PCM。

## 自动化验证

```bash
npm test            # 依次跑下面三套
npm run verify      # 页面内 19 项自检
npm run e2e         # 真实按钮点击的端到端链路
npm run wav         # 导出 WAV 并用 Node 解析二进制头
```

`verify-run.js` 覆盖的关键断言：

- WAV 时长精确（2.250s）、立体声、48kHz、左右声道均有真实信号且彼此不同。
- 四个可操作维度真实改变输出：频段、门限（错误滤波可切断主声源，衰减 >30dB）、
  左右声像、节拍/延迟（按步渲染）。
- 三种监听状态：静音输出为零、旁路与主输出可测量地不同。
- 无尾音：渲染窗口末端保留 >120ms 静音余量。
- 参数保存→重载→再次导出：时长、左右峰值、声道完全一致。
- 暂停后上下文 `suspended`、输出静默；恢复后继续；停止后活动节点归零（无未关闭节点）。
- 节拍漂移：在线步进间隔偏差 < 2ms。

`e2e-run.js` 通过真实点击验证播放/暂停/单步/三态监听/停止/重播，以及
“保存→改乱参数→重载→再导出”两次导出结果一致。

`wav-export.js` 解析导出文件的 RIFF/WAVE/fmt/data 头，核对 PCM 格式、
声道数、采样率、位深、数据长度、时长与峰值。

## 文件

- `index.html`：界面结构。
